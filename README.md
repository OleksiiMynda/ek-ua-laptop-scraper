# Парсер пропозицій ноутбуків з EK.ua

Програма для автоматизованого збору даних про пропозиції продажу ноутбуків із сайту [EK.ua](https://ek.ua/ua/).

## Зібрані дані для кожної пропозиції:
- **назва (модель)** ноутбука
- **опис (характеристики)**
- **ціна продажу** (у числовому форматі `int`)
- **місто**
- **магазин**

Результати зберігаються у файлі `laptops_ek_ua.json`.

## Встановлення залежностей

```bash
pip install -r requirements.txt
playwright install chromium
```

## Запуск програми

```bash
python scraper.py
```
